# Employee Salary Analysis

## Project Overview
This project analyzes employee salary data using Python.
It calculates the total, average, highest, and lowest salaries
and identifies the highest-paid and lowest-paid employees.

## Technologies Used
- Python
- Jupyter Notebook

## Dataset
The project uses sample employee names and salary values
stored in Python lists.

## Features
- Stores employee names and salaries.
- Calculates the total salary.
- Calculates the average salary.
- Identifies the highest salary.
- Identifies the lowest salary.
- Identifies the highest-paid employee.
- Identifies the lowest-paid employee.
- Verifies the calculated results.

## Sample Results
- Total Salary: ₹175,000
- Average Salary: ₹35,000
- Highest Salary: ₹45,000
- Lowest Salary: ₹25,000
- Highest-Paid Employee: Sanjay
- Lowest-Paid Employee: Ramya

## Python Functions Used
- sum()
- len()
- max()
- min()
- zip()
- index()

## Learning Outcomes
Learned how to use Python lists, loops, built-in functions,
and basic calculations for employee salary analysis.
